# Screenshots

Capture these from a running `po` (macOS, `cargo run -p po-app`), then commit
the PNGs here — the README embeds them:

1. `login.png` — the auth screen (noir background, amber "po" wordmark)
2. `chat-echo.png` — a chat with the echo provider: user bubble right, assistant left
3. `palette.png` — the cmd-k palette open with "session" typed
4. `settings.png` — the settings panel after a theme toggle
5. `approval.png` — a pending tool-approval card
6. `chat-engine.png` — a real nano-engine reply (with `local-engine` + a model)

Shooting tip: `screencapture -l <windowid> out.png` grabs one window cleanly.
