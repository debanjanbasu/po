1| ## 2. What gpui-ce provides (verified against the clone)
2| 
3| - **App model:** `gpui_platform::application().run(|cx: &mut App| …)` → `cx.open_window(WindowOptions, |_, cx| cx.new(MyView::new))`. Web: `gpui_platform::web_init()` + `application_with_web_backend(WebBackendPreference::Auto)`.
4| - **State:** `Entity<T>` + `impl Render for T` (`render(&mut self, &mut Window, &mut Context<Self>)`). Observers: `cx.observe` / `cx.subscribe` / `cx.observe_global`; mutation ends with `cx.notify()`. Globals: `trait Global` + `cx.set_global` / `cx.global::<G>()`. Element-local state: `window.use_state`. Stateless widgets: `RenderOnce`.
5| - **Async:** `cx.spawn` (foreground, `AsyncApp`), `cx.background_spawn` (pool), `Task<R>` cancellation-by-drop. `gpui_tokio` runs a real Tokio runtime in a `Global` and bridges `Tokio::spawn(cx, fut)` → GPUI `Task` — this is the bridge for every Veilid worker future.
6| - **Styling:** Tailwind-shaped fluent methods generated by macros (`flex()`, `flex_col()`, `items_center()`, `gap_2()`, `p_4()`, `text_sm()`, `bg()`, `text_color()`, `rounded_lg()`, `hover_style()`, `transitions()`, `backdrop_blur()`), driven by `StyleRefinement`. Colors via `rgb()/rgba()/hsla()`; appearance-aware palettes via the `Colors` pattern (`Colors::for_appearance(window)`).
7| - **Elements:** `div`, `svg`, `img`, `canvas` (custom drawing — QR render), virtualized `list`/`uniform_list` (chat list/conversation), `deferred`, `anchored` popups, `with_animation` (activity/toast motion). Text inputs/areas with IME, selection, undo, caret blink: `gpui_ce_elements::{editable_text::{text_input, text_area}, switch}`.
8| - **Windowing:** `TitlebarOptions { title, appears_transparent, traffic_light_position }` (custom `WindowChrome` port), `WindowKind::{PopUp, Dialog, AnchoredPopup, Floating}` (modals), `WindowDecorations` (Linux), bounds/activation/appearance observers (replaces `use_wry_event_handler`).
9| - **Assets:** `AssetSource` trait (`load`/`list`); web path is fetch or `include_bytes!`; fonts via `cx.text_system().add_fonts` (TTF/OTF — **no WOFF2**).
10| - **Web runtime:** one `<canvas>` per page, one top-level window, WebGPU→WebGL2 fallback, Trunk build/serve, threaded background executor only with `multithreaded` feature + cross-origin isolation (COOP/COEP headers — pattern in `crates/gpui_web/examples/hello_web/Trunk.toml` and its `.cargo/config.toml`).
11| - **Web limitations that hit this app:** no DOM/a11y tree (canvas-only rendering), no file pickers, no system notifications, no keychain, no screen capture; clipboard reads async; `open_url` works. Camera (QR scan), Web Share, localStorage are **not** GPUI services — the existing `web-sys` impls (`platform/qr_scanner/wasm_impl.rs`, `platform/share/wasm_impl.rs`, `platform/browser_storage.rs`) keep working unchanged.
12| - **Testing:** `test-support` feature, `TestApp` (gpui's own, distinct from this repo's Tandem harness), leak detection, bench support.

14| ## 3. API mapping (the port is mechanical once per pattern)
15| 
16| | Dioxus (today) | gpui-ce (target) |
17| |---|---|
18| | `LaunchBuilder…launch(App)` per platform in `main.rs` | `gpui_platform::application().run(...)` + `cx.open_window(...)`; web gets `web_init()` + `application_with_web_backend`; iOS/Android keep their native hosts and call the same closure (iOS via `main`, Android via `android_main` → the mobile backend's run hook) |
19| | `#[component] fn X() -> Element` + `rsx!` | `struct X { … }` + `impl Render` (stateful) or `RenderOnce` fn (stateless leaf) |
20| | `Signal<T>` / `use_signal` | `Entity<T>` field mutated via `cx` + `cx.notify()`; element-local via `window.use_state` |
21| | `GlobalSignal` (33 across 13 files: `SESSION`, `THEME`, `NETWORK_STATUS`, `CONVERSATION_META`, `PENDING_INVITES`, store revisions…) | `Global` structs owning the same data; `cx.set_global` at boot; `cx.observe_global` for UI rows that watched them; keep `ReadableExt`-style helpers as plain methods so call sites barely change |
22| | `use_memo` (73) | cheap derivations computed in `render`; expensive ones cached in an entity refreshed by `cx.observe` on inputs |
23| | `use_effect` (40) | `cx.observe`/`cx.subscribe`/`cx.observe_global` registered in the owning entity's constructor |
24| | `use_resource` (18) | `cx.spawn` + stored `Task` handle (drop = cancel); re-run by triggering an `Entity` version counter observed like the signal deps were |
25| | `spawn` / `spawn_forever` / `spawn_session_scoped` (79 + send.rs) | `cx.spawn` / `cx.background_spawn`; session-scoped variants keep their `SessionGuard` logic, now spawning from an `Entity` context instead of a scope |
26| | `use_drop` (7: Veilid shutdown, watchers) | `Drop` on the entity + `cx.observe_release`; process-exit paths move to the `Application` run-closure tail |
27| | `dioxus_router` `Routable`/`#[nest]`/`#[layout]`/redirects | hand-rolled router: same `Route` enum + path strings, an `ActiveRoute` entity, a `nav(to)` helper, history/deep-link sync; `NavLayout` dock becomes the shell's render wrapper |
28| | `class: "flex gap-2 …"` (563 sites) | fluent style methods (`flex().gap_2()…`); one-time port with a lint banning `class:` reentry |
29| | Tailwind + daisyUI themes (`shared/theme.css`, `overrides.css`) | `ui::theme` module: the bumblebee warm palette + dark theme expressed as `Hsla` tokens in an appearance-aware `Colors` struct; `ui-conventions.md` §Theme tokens carries over as Rust constants |
30| | `document::Style/Link`, `asset!`, manganis | `AssetSource` + `include_bytes!`; static web shell files via Trunk `index.html` |
31| | `dioxus::logger` | `tracing-subscriber` everywhere (already used on native); wasm: console layer via `tracing-wasm` or `console_log` |
32| | `use_wry_event_handler`, tao builders (`platform/window.rs`) | `WindowOptions`/`TitlebarOptions` + GPUI window observers (`observe_window_bounds/activation/appearance`) |
33| | `ErrorBoundary` / `?` in components | match on `Result` in `render`; keep `report_nonfatal!` paths identical |
34| | `devtools` feature / dx hot-patch | gpui `inspector` feature + debug overlay; gpui-ce hot-patching (see its `docs/pages/hot-patching.typ`) evaluated in Phase 0 |
35| | e2e web surface: Playwright DOM (`#login-username-input`, `aria-label` fills, `textContent` asserts) | **Gone on canvas.** Web surface asserts move to the existing `event=` seam markers (`e2e-seams` feature) + pixel/screenshot checks; DOM-driving moves to gpui's own `TestApp` in Rust tests where possible |

37| ## 4. Target tree
38| 
39| ```
40| src/
41|   main.rs                  # entry per target (replaces dioxus launch edge)
42|   ui/
43|     mod.rs    app.rs       # root view, auth-phase machine (ex ActiveRouter)
44|     router.rs              # Route enum, nav(), deep-link + restore mapping
45|     theme.rs               # palette/appearance tokens (ex daisyUI themes)
46|     widgets/               # text fields, buttons, modal, toasts, dock, qr views
47|     screens/               # auth, onboarding, chat, settings, totp, placeholders
48|   (domain modules unchanged: chat/ user/ storage/ sync/ veilid/ models/ …)
49| ```
50| 
51| `Cargo.toml` features become: `default = []`, `web`, `desktop`, `mobile`, `aimd-dht`, `veilid-stats`, `e2e-seams` (only `devtools` dies). Web build: `trunk serve/build --release` with COOP/COEP; desktop: `cargo build` + existing bundling scripts (minus dx); mobile: cargo-ndk + `xtool` per the mobile backends' packaging flow.
